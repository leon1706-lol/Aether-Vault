# `development/` — Project History & Audit Trail

Everything here is written *by* the development process *for* future development: what was
built, when, why, and every problem found along the way. See the
[main README](../README.md) for the project overview.

## Contents

| File | Purpose |
|---|---|
| [`architecture.md`](architecture.md) | What the system **is** — one contract section per subsystem (staging, commit, sync, merge, restore, GC, auth, transport hardening, webui, plugins, release), system/tech-stack diagrams, module map, testing-and-verification map |
| [`infrastructure.md`](infrastructure.md) | How to **run** it — Docker compose stack, environment variables, Protected mode, database migrations, rate limiting ops, releases (PyPI/GitHub Releases/GHCR), PostgreSQL inspection SQL |
| [`CHANGELOG.md`](CHANGELOG.md) | The full build-phase history (Phases 1–46+), newest at the end. Each phase records files touched, the problem/feature, and how it was verified |
| [`Probleme.md`](Probleme.md) | Severity-rated audit log of correctness, performance and security findings. Every entry follows Problem → Fix → Verification with a 🟢/🟡/🔴 status |
| [`BENCHMARKS.md`](BENCHMARKS.md) | Captured cross-tool benchmark results (generated by `av benchmark --markdown`) with methodology notes and single-machine caveats |
| [`CONTINUATION-V1.2.0.md`](CONTINUATION-V1.2.0.md) | V1.2.0 milestone record: shipped scope, verification snapshot, post-release backlog |
| [`CONTINUATION-V1.2.2.md`](CONTINUATION-V1.2.2.md) | V1.2.2 cycle record: engine image consolidation + architectural gap closure, decisions, verification state |
| `logo.png` | Project logo used by the main README |

## Conventions

- New work appends the next sequential **Phase** to `CHANGELOG.md` and, if a real bug was
  found during manual debugging, a matching severity entry to `Probleme.md`
  (`Aether-vault-Obsidian-Vault/Essential-Tasks.md` documents the full wrap-up checklist).
- `BENCHMARKS.md` is machine-generated — re-run `av benchmark --markdown` rather than
  hand-editing numbers.
